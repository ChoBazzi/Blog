# 비교·측정 실험 구성 템플릿

완성 글이 아닌 작성 안내이다. 실제 작성 시 안내를 본문으로 대체하고 [문체 지침](../style-guide.md)의 frontmatter를 적용한다. 예상값이나 합성 수치를 실제 결과로 옮기지 않는다.

## 질문과 가설

무엇을 비교하거나 확인하려는지 하나의 질문으로 정리한다. 가설과 이미 관찰한 결과를 구분하고 독자가 얻을 내용·적용 범위를 밝힌다.

## 조건과 기준선

하드웨어, OS, 런타임·라이브러리 버전, 입력 데이터, 부하, 캐시·워밍업 상태, 네트워크 조건, 기준선과 비교 기준을 기록한다. 서로 다른 조건이 있다면 숨기지 않는다.

## 절차

실행 주체·명령·반복 횟수·측정 도구·단위·집계 방식·이상치 처리와 원자료 위치를 연결한다. 결과가 좋아 보이는 표본만 선택하지 않는다. 실제 실행 전 부작용과 공개 가능 범위를 확인한다.

## 결과

원자료가 있는 결과만 적는다. 기준선과 변경 후 값, 표본·반복, 단위를 함께 보여준다. 숫자가 없으면 미측정으로 표시하며 추정 개선율을 만들지 않는다. 그림이 필요해도 원자료 없이 자동 생성하지 않는다.

## 해석

관찰과 해석·가설을 분리한다. 해당 환경의 결과를 일반적인 우열이나 운영 성과로 확대하지 않는다. 변동성·교란 요인·반례를 확인한 범위에서 설명한다.

## 재현 방법과 한계

공개 가능한 입력·코드·명령과 환경 정보를 제공한다. 비공개 데이터·원본 로그는 노출하지 않는다. 재현하지 못한 조건과 다음에 확인할 사항은 미완료로 명시한다. 핵심 수치를 지지할 환경·절차·원자료가 빠졌으면 본인 검토 대기로 넘기지 않는다.
