NAS에서 GitHub로 연결하는 Runner

연결과 작업 전달의 방향

실선 HTTPS 443은 Runner가 시작하는 outbound 연결이다. 반대 방향의 점선은 작업 전달이며 GitHub가 NAS에 새 inbound 연결을 연다는 뜻이 아니다.

호스트 Docker 사용

컨테이너 Docker CLI 29.1.3에서 DOCKER_API_VERSION=1.41을 설정하고 NAS socket을 사용한다. 컨테이너 내부 daemon이나 services: 대신 호스트 Engine과 docker run으로 PostgreSQL CI를 구성했다.

독립 파일에서는 NanumSquare가 없을 때 시스템 글꼴로 대체된다.
